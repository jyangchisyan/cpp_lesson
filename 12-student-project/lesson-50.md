# 第 50 課：驗證輸入

[返回本類索引](README.md)

對照目前累積版本 [student_average.cpp](student_average.cpp)。

## 5 分鐘重點

先確認學生數量讀取成功且非負；每筆名字和分數也要檢查 `std::cin` 是否成功。發現無效輸入就印「輸入錯誤」並結束；應在**建立或覆寫報告前**完成驗證，保留舊的有效報告。

```cpp
if (!(std::cin >> count) || count < 0) {
    std::cerr << "輸入錯誤\n";
    return 1;
}
```

## 一道練習

分別測 `-1`、非數字人數，以及學生資料少一個分數；都不能產生部分報告。再測有效資料仍可正常輸出。
