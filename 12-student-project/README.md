# 學生資料小專題：第 44–61 課

這十八課都逐步修改同一份 [student_average.cpp](student_average.cpp)；目前檔案是**第 61 課版本**，不是每一課各自的歷史快照。核取方框用來記錄重新閱讀的進度。

- [ ] [**第 44 課：收集學生與平均分數**](lesson-44.md) — `Student` 將名字和分數組合，`vector<Student>` 儲存多筆資料；浮點除法算平均，`n = 0` 顯示「沒有學生」。
- [ ] [**第 45 課：找最高分**](lesson-45.md) — 用 `std::max_element` 比較分數，印出最高分學生名字；只在非空時取用結果。後續課程改成先排序再用 `front()`。
- [ ] [**第 46 課：依分數排名**](lesson-46.md) — 使用 `std::sort`，分數高者排前；平均、最高分名字、各學生排名依序輸出。
- [ ] [**第 47 課：寫入報告**](lesson-47.md) — `std::ofstream("report.txt")` 同時把相同分析結果寫入檔案；空集合時檔案只寫「沒有學生」。
- [ ] [**第 48 課：組合一次、輸出兩處**](lesson-48.md) — `std::ostringstream` 先組成完整報告，`output.str()` 共用於 `std::cout` 與檔案，避免內容重複維護。
- [ ] [**第 49 課：檢查報告可寫**](lesson-49.md) — `if (!report)` 時將「無法寫入報告」送至 `std::cerr`，以 `return 1` 結束。
- [ ] [**第 50 課：驗證輸入**](lesson-50.md) — 檢查學生數量與每筆名字、分數；無效資料先印「輸入錯誤」並結束，不覆寫舊報告。
- [ ] [**第 51 課：抽出平均函式**](lesson-51.md) — `averageScore(const std::vector<Student>&)` 只讀學生資料；非空時才呼叫，避免除以零。
- [ ] [**第 52 課：抽出排序函式**](lesson-52.md) — `sortByScore(std::vector<Student>&)` 修改容器次序，因此參數不能加 `const`。
- [ ] [**第 53 課：同分以名字排序**](lesson-53.md) — 比較時先按分數降序，再按名字升序；排序後用 `students.front().name` 當最高分名字，空集合不可取 `front()`。
- [ ] [**第 54 課：計算成績中位數**](lesson-54.md) — 排序後找中間位置；偶數人取中間兩位平均，除法前轉為浮點數。練習：在平均分數後加入中位數，並同步輸出至畫面與報告。
- [ ] [**第 55 課：固定小數位數**](lesson-55.md) — `std::fixed` 搭配 `std::setprecision(2)`，讓平均數與中位數都顯示兩位小數，畫面與報告格式一致。
- [ ] [**第 56 課：統計及格人數與及格率**](lesson-56.md) — 用 `std::count_if` 統計至少 60 分的人數，再以浮點除法算百分比；零人時不計算。
- [ ] [**第 57 課：驗證分數範圍**](lesson-57.md) — 只接受 `0` 到 `100` 分；無效資料在開檔前結束，避免覆寫既有報告。
- [ ] [**第 58 課：篩選不及格學生**](lesson-58.md) — `std::copy_if` 配合 `std::back_inserter` 將低於 60 分的學生複製到新容器，再輸出名單。
- [ ] [**第 59 課：把分數轉換成等第**](lesson-59.md) — 依分數門檻回傳 `A` 到 `F`，在排名的每位學生後顯示等第。
- [ ] [**第 60 課：統計各等第人數**](lesson-60.md) — 用 `std::map<char, int>` 計數，依 `A B C D F` 固定順序輸出，未出現的等第也要顯示 `0`。
- [ ] [**第 61 課：檢查重複姓名**](lesson-61.md) — 用 `std::set<std::string>` 記錄已讀姓名；`insert(...).second` 為 `false` 時拒絕輸入，保留舊報告。

目前有學生時的輸出順序是：**平均分數 → 中位數 → 及格人數與及格率 → 最高分名字 → 每位學生的「名字 分數 等第」→ 不及格名單 → 各等第人數**。例如輸入 `3`、`Bob 90`、`Amy 90`、`Cathy 80`，中位數是 `90.00`、及格率是 `100.00%`，前兩個排名是 `Amy 90 A`、`Bob 90 A`，最後的等第統計是 `A=2 B=1 C=0 D=0 F=0`。

在本資料夾編譯與執行，`report.txt` 才會產生在這裡；有效執行會覆寫舊報告：

```sh
cd 12-student-project
g++ student_average.cpp -o student_average
./student_average
```
